# User guide

Each page follows one block of the course and pairs the statistical idea with the
`engstats` calls that carry it out. 

- [Descriptive statistics](descriptive.md): summaries, spread, and shape of one variable.
- [Hypothesis testing](inference.md): t-tests, chi-square, one-way ANOVA.
- [Regression](regression.md): simple, multiple, and polynomial least squares.
- [Plotting](plotting.md): the plot catalogue and how to combine plots.
